## Как загрузить аудио

1. Откройте: https://github.com/ynkozlova-cpu/govorun-ai/upload/main/demos  
2. Загрузите файлы с **латинскими именами** из таблицы выше (без пробелов и кириллицы).  
3. Commit changes.

Имена на латинице нужны, чтобы ссылки на Pages/raw работали стабильно.

## Рекомендуемые публичные ссылки (после загрузки)
